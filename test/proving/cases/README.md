# Reviewed case exports

This public directory contains only case exports reviewed and authorized for
publication. The empty index is intentional. The controlled runner baseline in
`../goals/results/index.json` remains separate and not run.

Private manually captured cases and their bounded ZIPs stay in owner storage
outside the public checkout until the exact projection is approved. Do not
commit raw journals, original private prompts, machine addresses, credentials,
or private archive receipts here. See the public evaluation case protocol in
`docs/public/overview/evaluation-case-records.md` and the explicit-selection
packager at `scripts/proving/archive_case.py`.
