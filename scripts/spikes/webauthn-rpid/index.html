Leg 1 — the browser's RP ID validator (runs by itself)

These four ran the moment the page loaded, and are already recorded. Each calls create() under an AbortController that fires after 2.5s: RP ID validation happens before any authenticator is consulted, so the verdict arrives without an authenticator having to exist — which is why this leg needs no hardware and no human.

Read the controls first. example.com must be REJECTED or the discriminator is not firing and none of the other rows mean anything. localhost must ALSO be rejected: it is refused as an RP ID for this very origin only if the browser is treating localhost as a public suffix, which is the exact behaviour that makes memql.localhost a registrable domain and the parent-RP-ID case legal.
